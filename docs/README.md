# Docs — organized by week

Docs are grouped into per-week folders that mirror `code/`. Generated files are written
straight into their week folder by the script named in "Generated by"; the rest are
hand-written. Two cross-cutting files stay at the `docs/` root.

## Root (cross-cutting)

- `README.md` — this index.

## week1/ — setup, audit, Reddit exploration

- `subreddit_selection_and_counts.md` — subreddit selection + per-subreddit/hurricane counts.

## week2/ — collection + unified VADER

- `vader_reproduction_50row.csv` — 50-row VADER new-vs-original comparison. _Generated by_ `code/week2_collection_vader/run_vader_facebook.py`.

## week3/ — RoBERTa + agreement

- `roberta_processing_log.md` — RoBERTa scoring stats (truncation, runtime, failures). Hand-pasted from `code/week3_roberta_agreement/RoBERTa.ipynb`.

## week4/ — BERTopic + annotation

- `bertopic_run_log.md` — per-file `min_topic_size`, topic counts, outlier rates. Hand-pasted from `code/week4_bertopic/BERTopic.ipynb`.
- `Topic Codebook.md` — reconciled cross-source topic categories (final).
- `topic_review.md` — per-file topic overlap/merge review (joint).
- `interannotator_kappa.md` — human inter-annotator Cohen's κ (sentiment + gratitude). _Generated by_ `code/week5_hypotheses/build_ground_truth.py` (a Week-4 deliverable, but its script lives in the week5 folder).

## week5/ — hypothesis testing

- `hypothesis_tests_results.md` — H1/H3/H4/H7, VADER + RoBERTa. _Generated by_ `code/week5_hypotheses/hypothesis_tests_jose.py`.
- `h2_temporal_results.md` — H2 OLS temporal trajectory. _Generated by_ `code/week5_hypotheses/h2_temporal.py`.
- `h5_subreddit_results.md` — H5 subreddit tiers. _Generated by_ `code/week5_hypotheses/h5_subreddit.py`.
- `method_validation_report.md` — VADER/RoBERTa vs the 400-item gold standard. _Generated by_ `code/week5_hypotheses/evaluate_methods.py`.
- `statistical_results_table.md` — formal 7-hypothesis × 2-method grid. _Generated by_ `code/week5_hypotheses/results_table.py`.
- `statistical_results_summary.md` — verdict view of the same grid (hand-written).

> Note: `chi_square_results.md` (topic distributions) is written to `data/merged/`, not here, by `code/week4_bertopic/topic_distributions.py`.
