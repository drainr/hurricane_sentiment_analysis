# Docs — indexed by week

Docs are grouped here by the project week that produced them. Files stay flat in
`docs/` (many are **generated** by scripts with a hard-coded `docs/` output path,
so moving them would mean editing those scripts). "Generated by" names the script
that writes the file; the rest are hand-written.

## Cross-cutting
- `decision_log.md` — running log of every methodological decision (Week 8 deliverable, maintained throughout).

## Week 1–2 — setup, collection, unified VADER
- `subreddit_selection_and_counts.md` — subreddit selection + per-subreddit/hurricane counts.
- `vader_reproduction_50row.csv` — 50-row VADER new-vs-original comparison. *Generated by* `week2/run_vader_facebook.py`.

## Week 3 — RoBERTa + agreement
- `roberta_processing_log.md` — RoBERTa scoring stats (truncation, runtime, failures). From `week3/RoBERTa.ipynb`.

## Week 4 — BERTopic + annotation
- `bertopic_run_log.md` — per-file `min_topic_size`, topic counts, outlier rates.
- `Topic Codebook.md` — reconciled cross-source topic categories (final).
- `topic_review.md` — per-file topic overlap/merge review (joint).
- `interannotator_kappa.md` — human inter-annotator Cohen's κ (sentiment + gratitude). *Generated by* `week5/build_ground_truth.py` (a Week-4 deliverable, but its script lives in the week5 folder).

## Week 5 — hypothesis testing
- `hypothesis_tests_results.md` — H1/H3/H4/H7, VADER + RoBERTa. *Generated by* `week5/hypothesis_tests_jose.py`.
- `h2_temporal_results.md` — H2 OLS temporal trajectory. *Generated by* `week5/h2_temporal.py`.
- `h5_subreddit_results.md` — H5 subreddit tiers. *Generated by* `week5/h5_subreddit.py`.
- `method_validation_report.md` — VADER/RoBERTa vs the 400-item gold standard. *Generated by* `week5/evaluate_methods.py`.
- `statistical_results_table.md` — formal 7-hypothesis × 2-method grid. *Generated by* `week5/results_table.py`.
- `statistical_results_summary.md` — verdict view of the same grid. *Generated by* `week5/results_table.py`.

> Note: `chi_square_results.md` (topic distributions) is written to `data/merged/`, not here, by `week4/topic_distributions.py`.
